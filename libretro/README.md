# GBA 双屏 — GBA DS as a libretro core

This branch (`youdian`) builds [GBA DS](https://github.com/kyannon/gba-ds) as a libretro core,
`gbads_libretro_android.so`, for the 游典 (Youdian) Android frontend, where it is listed as
**游典 · GBA 双屏** (GBA dual screen). It is not part of upstream GBA DS.

## What it does

GBA DS's own game code runs every frame (`src/game.c`, through `libretro/lr_game.inc`): the game on
GBA DS's mGBA wrapper, and everything its second screen does — the map and status capture on a silent
copy of the game, the HUD split, the pinball tables over both screens, status snapshots, fights, and the
game's logo when there is nothing else to show. The 64 supported games and what each shows are GBA DS's
own ([Supported games](https://github.com/kyannon/gba-ds/wiki/Supported-games)); any other GBA game
plays on one screen.

The core outputs one 240 × 320 picture: the game screen above, the second screen below, a GBA pixel
each. The frontend splits it over a dual-screen handheld's two screens, or shows both stacked.

Save states are mGBA's libretro core's (`mCoreSaveStateNamed`), so states go both ways between this
core, mGBA's libretro core and GBA DS. Battery saves are the same `.srm` as mGBA's.

## Files

| | |
|---|---|
| `libretro/gbads_libretro.c` | the libretro API: input, picture, sound, saves, states, cheats |
| `libretro/lr_game.inc` | included at the end of `src/game.c`: opens a game and runs a frame of GBA DS's loop without its windows, menus or sound device |
| `libretro/shim.c` | the parts of SDL and `ui.c` that code calls: textures as pixels in memory, surfaces, the logo |
| `libretro/stubs.c` | generated by `libretro/make_stubs.py`: the rest of SDL / `ui.c` named but never called here |
| `src/emu.c`, `src/emu.h` | states in mGBA's libretro form; errors counted (a pinball table's copies that keep failing are closed) |
| `tools/harness.c` | `auto`: plays into a game by itself and writes a state, for testing both GBA DS and this core |

## Building (Android, arm64)

Needs the Android NDK r27, CMake and Ninja.

```sh
. scripts/mgba-options.sh
git clone https://github.com/mgba-emu/mgba.git deps/mgba && git -C deps/mgba checkout "$MGBA_COMMIT"
git clone --depth 1 -b "$SDL_BRANCH" https://github.com/libsdl-org/SDL.git deps/SDL2   # headers only
NDK=/path/to/ndk/27.x
cmake -S deps/mgba -B deps/mgba/build-android -G Ninja \
  -DCMAKE_TOOLCHAIN_FILE=$NDK/build/cmake/android.toolchain.cmake -DANDROID_ABI=arm64-v8a -DANDROID_PLATFORM=android-24 \
  "${MGBA_OPTS[@]}"
cmake --build deps/mgba/build-android --target mgba
cmake -S libretro -B build-libretro -G Ninja \
  -DCMAKE_TOOLCHAIN_FILE=$NDK/build/cmake/android.toolchain.cmake -DANDROID_ABI=arm64-v8a -DANDROID_PLATFORM=android-24 \
  -DCMAKE_BUILD_TYPE=Release -DMGBA_SRC=$PWD/deps/mgba -DMGBA_BUILD=$PWD/deps/mgba/build-android
cmake --build build-libretro    # build-libretro/gbads_libretro.so
```
